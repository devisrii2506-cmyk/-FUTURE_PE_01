# AI Website Copy Generator – Sritik Cafe

## Project Overview

This project demonstrates how Prompt Engineering can be used to generate professional website content for a real local business.

The selected business is **Sritik Cafe**, a modern café located in Sainikpuri.

Using a structured AI prompt, a complete website content package was generated, including homepage copy, menu descriptions, customer reviews, online ordering content, table reservation content, and call-to-action sections.

---

## Business Chosen

**Business Name:** Sritik Cafe

**Location:** Sainikpuri, Hyderabad

**Business Type:** Modern Coffee Café

---

## Project Objective

The goal was to create website-ready content that helps:

* Increase customer visits
* Support online food ordering
* Enable table reservations
* Build customer trust
* Improve online presence

---

## Tools Used

* ChatGPT
* lovable

---

## Prompt Framework

The prompt was structured into the following sections:

1. Business Details
2. Project Objectives
3. Website Requirements
4. Design Requirements
5. Content Generation Instructions

This structured approach helps generate consistent and reusable website content for local businesses.
