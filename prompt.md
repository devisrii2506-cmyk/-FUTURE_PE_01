#  AI Website Generator Prompt – Sritik Cafe

Act as a web developer, UI/UX designer, and conversion copywriter.

Design a complete modern, mobile-friendly website for a café business.

## Business Details
- **Name:** Sritik Cafe  
- **Location:** Sainikpuri  

##  Objective
Generate website content that increases:
- Walk-ins
- Online orders
- Table reservations
- Brand trust

## Required Website Sections

1. Hero Section (Headline, Subheadline, CTA buttons)
2. About Section (Story + vibe)
3. Menu Section (with realistic items + prices)
4. Online Ordering System (pre-order before arrival)
5. Table Reservation System (booking form UI text)
6. Features Section (WiFi, ambience, service, etc.)
7. Reviews Section (5 realistic customer reviews)
8. Location Section (Google Maps + directions CTA)
9. CTA Section (Visit, Order, Book Table)
10. Footer


##  Design Requirements
- Modern cafe UI
- Mobile-first design
- Clean and simple language
- Realistic content (not generic AI text)


##  Avoid
- Overly formal tone
- Repetitive AI wording
- Unstructured output
